What I built

First a traffic light controller in Verilog: a finite state machine with a testbench, simulated in Icarus Verilog and checked in VCD waveforms. Then two designs in Clash, a min-max Mealy machine and a small stack-based processor.

The last assignment was a Sobel edge detection accelerator with an AXI4-Stream interface, so it can sit in a real SoC pipeline.

How the accelerator works

Pixels arrive one per clock as a stream. Line buffers built from shift registers keep the previous rows, so the design always has a 3×3 window of pixels ready for the Sobel kernel.

AXI4-Stream only moves data when tvalid and tready are both high. When the next stage pulls tready low, every pixel has to stay where it is until it goes high again. Getting that right is what makes the accelerator usable in a larger system.

My part

I designed the shift-register architecture that feeds the convolution window, fixed the s_axis_tready handshake and the 1D convolution transpose, checked the design against the RTL schematic and wrote parts of the report.

What I learned

Building a processor in Clash is where I properly understood how a functional description turns into gates.

Result

A working accelerator with correct AXI4-Stream backpressure, verified in simulation, with a report on the design decisions.
